# RegiNor Lite

A lightweight starter workspace for the RegiNor Lite project.

## Structure

- `index.html` — landing page
- `styles.css` — styling
- `script.js` — small interactive behavior

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
cd ~/RegiNor-Lite
python3 -m http.server 8000
```

Then visit http://localhost:8000
