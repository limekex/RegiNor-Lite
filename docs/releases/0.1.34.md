# 0.1.34 – kortkodegenerator og utvidede filtre

Testutgave 27. september 2026.

Under **RegiNor Lite → Kortkodegenerator** velger administrator eller kursansvarlig kursutvalg og visning, trykker «Lag kortkode» og kopierer resultatet til Avada eller WordPress. Generatoren endrer ingen kurs eller sider.

Kortkoden og kursblokken støtter inkludering/utelatelse av dansestil, nivå, ukedag, sted, sal, instruktør, kursperiode, bestemte kurs, påmeldingsstatus og prisgrunnlag. Pris, vanlig starttid og antall ikke-avlyste kurskvelder har inklusive fra-/til-grenser. Fremheving, drop-in og eksisterende visningsvalg kan kombineres med filtrene.

Flere valg innen samme felt betyr enten eller; ulike felt må passe samtidig. Utelatelse vinner. URL-parametre kan ikke utvide kortkodens kursutvalg. Ugyldige grenser viser ingen kurs og forklares i generatoren. Bare offentlig tilgjengelige kurs vises, fortsatt én kursperiode om gangen.

Dansestil filtreres på felles kildetekst og instruktører på hovedspråkets profilreferanser. Sal, sted og starttid følger grunnoppsettet; filtrene kutter ikke enkeltkvelder ut av et kurs. Pris gjelder ordinær vist kurspris med eksisterende grunnlag per person eller par.

[Brukerveiledning og eksempler](../KORTKODER-OG-KAMPANJESIDER.md). [Nybegynnerforslaget](../LANDINGSSIDE-NYBEGYNNER.md) er oppdatert med Salsa-filter.
