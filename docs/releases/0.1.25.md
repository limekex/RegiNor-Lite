# 0.1.25 – numerisk kapasitet og uspesifiserte grenser

Testutgave 26. september 2026.

- Kategoritall i administrasjonen og på kursprofilen vises uten «Opptil»: et tall, 0 ved fullt eller ∞ ved ubegrenset. Kursenes statusbadger beholdes.
- Manglende/null grense i et gyldig LetsReg-svar regnes som ubegrenset. Kjente positive grenser eller rapportert ledighet begrenser fortsatt tallet. Par vises samlet og krever plass til begge deltakere.
- Negative/ugyldige tall, et feilet API-oppslag eller en manglende kategori blir ikke ubegrenset. Normaliseringen bevarer forskjellen mellom manglende innstilling og ugyldig verdi. Eldre tvetydige observasjoner avklares ved neste vellykkede kontroll; ingen engangstømming av siste kjente status eller ekstra API-kall.
- Kontrolltid og felles merknad om faktisk tilgjengelighet hos LetsReg beholdes. Numerisk visning er ikke en leverandørgodkjenning av delte kapasitetspooler/reservasjoner.

Roadmapen er også oppdatert med prosjekteiers godkjenning av visuell produksjons-/Avada-prøve, kalendernedlasting, iPhone-kursreise og målingsoppsett. Cron/republisering har positive driftsobservasjoner. LetsReg-status/hybridrapport prøves videre når salg pågår; kursansvarligrolle og kalenderabonnement gjenstår.

Rikere kalenderinnhold er foreslått som M4.2c og er ikke implementert i denne utgaven. Kalendernavn finnes allerede. Ingen kalenderidentiteter, målehendelser eller produksjonsinnstillinger er endret.

## Verifikasjon

- `composer check`: 231 tester / 573 assertions og syntakskontroll består. Regresjonsprøvene skiller uspesifisert grense fra ugyldig verdi, manglende svar/kategori og eldre observasjoner.
- `npm run test:registration-status`: 95 kontroller med syntetiske API-svar består, inkludert numerisk visning, beholdt kapasitet, salgsvinduer og statusvalg.
- `npm run test:capacity`: 39; `npm run test:storage`: 65; `npm run test:public`: 119; `npm run test:public-http`: 83 – består.
- `npm run test:interface`: DOM-/skjemaprøver består. Testdata ryddet.
- Første statusprøve traff en utdatert testforventning om HTML-taggen i administrasjonstabellen; forventningen ble rettet og hele prøven bestod ved ny kjøring.

Ingen live API-kall eller produksjonsprøve er utført av kodeagenten i denne leveransen. Kalender-, TEC-, samtykke- og målingskode er ikke endret eller testet på nytt. Brukerens rapporterte eksterne prøver er ført separat i roadmapen.

POT, ZIP-integritet, samsvar mellom alle 126 runtime-filer og kildekoden, samt `git diff --check` er kontrollert.
