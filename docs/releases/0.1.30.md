# 0.1.30 – instruktører på publiserte kurs

Testutgave 27. september 2026.

Publiserte enkeltkurs har nå **Instruktører → Lagre instruktører**. Legg til, bytt eller fjern alle uten å avpublisere kurs eller periode. Valget gjelder alle kommende, ikke-påbegynte og ikke-avlyste kvelder, også egne instruktørvalg. Historikken beholdes. Rettigheter, versjon og dobbeltbooking kontrolleres på serveren. Kalenderabonnementets innhold oppdateres.

Kurskort viser instruktørnavn som tekst. På enkeltkurset vises små profilkort med navn, lenke og profilbilde når tilgjengelig. Instruktørene på gjenstående aktive kvelder vises; gamle tildelinger beholdes i kurskveldenes historikk.

## Kortkode på instruktørprofilen

```text
[reginor_instructor_courses]
```

På en annen side, angi profilens WordPress-ID:

```text
[reginor_instructor_courses instructor_id="123"]
```

Viser kort fra alle offentlige perioder hvor instruktøren fortsatt har undervisning, uten filter eller visningsvalg. Dager og klokkeslett hentes fra de faktiske kurskveldene. Instruktørtypen må være valgt i RegiNor-oppsettet. Profiler må være publiserte og uten passord. WPML-koblede profiler støttes; kursdata kopieres ikke. Sidens egne metadata beholdes. Samme cachebeskyttelse som kursoversikten brukes.
