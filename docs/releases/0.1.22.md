# 0.1.22 – erklært støtte for WP Consent API

Testutgave 25. september 2026. RegiNor fulgte Complianz og lyttet til samtykkehendelser, men manglet erklæringen som WP Consent API bruker i Nettstedhelse.

## Endring

- Hovedfilen registrerer den dokumenterte støttekroken for pluginens egen filidentitet. Erklæringen gjelder bare RegiNor, og er tilgjengelig uansett om måling er aktivert.
- Når WP Consent API finnes, kontrolleres `wp_has_consent` for statistikk og markedsføring i både JavaScript og PHP. Et avslag der kan ikke overstyres av et tidligere samtykke fra Complianz.
- Eksisterende krav om Complianz og eksplisitt nettlesersamtykke beholdes. Uten Consent API brukes fortsatt Complianz. Consent API alene aktiverer ikke måling.
- Tilbaketrekking stopper nye hendelser, avbryter pågående måling og forsøker å slette økten. Sletting blokkeres ikke av at samtykke er trukket tilbake. Ingen kode gir samtykke på vegne av besøkeren eller endrer Google-samtykke.

Kortkodefunksjonene fra 0.1.21 og kladdrettingen fra 0.1.20 følger med.

## Kontroll etter oppdatering

Installer ZIP-en over eksisterende RegiNor Lite og åpne **Verktøy → Nettstedhelse** på nytt. RegiNor skal ikke stå som en utvidelse uten erklært støtte. Samlevarselet kan fortsatt stå hvis andre utvidelser mangler erklæring.

Prøv avvisning, bare statistikk, statistikk og markedsføring, og tilbaketrekking i det faktiske Complianz/GTM-oppsettet. Ingen produksjonsinnstillinger eller samtykkevalg er endret av denne leveransen.

Kilder: [registrering og kategori-API](https://wordpress.org/plugins/wp-consent-api/), [offisiell PHP-kilde](https://github.com/WordPress/wp-consent-level-api/blob/master/inc/api-functions.php). [Prosjektets samtykkeflyt](../MARKEDSFORING-OG-ATTRIBUSJON.md#complianz-og-datalagring).

## Verifikasjon

Nye regresjonsprøver dekker avslag, tillatelse og tilbaketrekking via Consent API mens Complianz fortsatt tillater samme kategori, samt at Consent API alene ikke starter måling. Nettleserprøven gjenskapte manglende håndheving av API-avslag før rettingen.

- `npm run test:journey`: 55 kontroller består.
- `npm run test:analytics`: 36 kontroller består; syntetiske data ryddet.
- `npm run test:wordpress`: oppstart og avgrenset støtteerklæring består.
- `composer check`: 230 tester / 565 assertions og syntakskontroll består.
- `git diff --check`: består.
- `npm run i18n:pot` og `npm run package`: består. Alle 126 runtime-filer i ZIP-en er kontrollert byte for byte mot kildefilene; ZIP-integriteten er kontrollert.

WordPress-prøven bruker Complianz-/Consent API-stubber; faktisk Nettstedhelse og GTM/GA4 på nettstedet er ikke verifisert her. Generelle kurs-/layout-, lagrings-, TEC- og kapasitetsprøver er ikke kjørt på nytt for denne samtykkeendringen.
