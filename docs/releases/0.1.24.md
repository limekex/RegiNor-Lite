# 0.1.24 – enkeltkvelder og kalenderens tidsakse

Testutgave 25. september 2026.

- Kurs med én kveld bruker entallsdag, for eksempel **Lørdag**, og **Dato** i kurskort og kursprofil. Kalenderkortet viser datoen også når kurset ligger før eller etter ordinær periodestart.
- Kurs over flere kvelder beholder flertallsdag og **Oppstart**. En kalenderdag med bare enkeltkvelder får entallsoverskrift; ved blandet utvalg beholdes flertall og hvert enkeltkurs viser sin dato.
- Hver kalenderdag starter ved sitt første viste kurs og slutter ved sitt siste. Et kurs kl. 13 på lørdag gir dermed ingen tomme timer før mandagens kveldskurs.
- Saler samme dag deler fortsatt tidsakse. Opphold mellom dagens kurs beholdes. Tidsaksen følger også filtrering og kortkodens kursutvalg, og korte dagskolonner strekkes ikke til nabodagens høyde.

Endringen gjelder offentlig presentasjon. Faktiske kursøkter og eksisterende regler for datoer, publisering og påmelding beholdes.

## Verifikasjon

- `npm run test:public`: 119 kontroller består. Nye regresjonsprøver dekker enkeltkvelder, tidligere/senere dato, blandede kurs, separate dagstider, salplassering og filtrering.
- `npm run test:public-http`: 83 kontroller består.
- `npm run test:admin`: 117 kontroller består, inkludert publiseringsflyt for tidligere introøkt og dens faktiske dato i kalenderen.
- `npm run test:interface`: DOM-/skjemaprøver består.
- `composer check`: 230 tester / 565 assertions og syntakskontroll består. Lokal Composer gir eksisterende deprecation-meldinger fra sine egne avhengigheter under PHP 8.5.

Testene har ryddet sine syntetiske data. Visuell prøve i faktisk Avada/staging er ikke utført. WordPress-oppstart, lagrings-, kapasitet-, TEC- og målingsintegrasjoner er ikke endret og er ikke testet på nytt i denne leveransen.

POT-generering, pakking og `git diff --check` består. Alle 126 runtime-filer i ZIP-en samsvarer byte for byte med kildefilene, og ZIP-integriteten er kontrollert.
