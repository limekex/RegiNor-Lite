## Korte statusmerker

Kort, kalender og kursprofil bruker samme korte statusetiketter:

- Påmelding Tilgjengelig
- Åpner snart
- Fullt
- Drop-in
- Fullt - Venteliste aktiv
- Stengt
- Avlyst
- Må avklares

Avsluttet beholdes for ferdige kurs. Merket henter nå teksten fra effektiv påmeldingsstatus, slik at kapasitetens hjelpetekst ikke erstatter etiketten. Statuslogikk, bakgrunnskontroll, siste kjente kapasitet, påmeldingslenker og sporingsattributter er uendret.

## HTML-støtte – kontrollert eksisterende funksjon

Import og lokal lagring bevarer enkel, renset HTML i kursbeskrivelse, nivå/forkunnskaper, partnerinformasjon og prisvilkår. Frontend viser avsnitt, linjeskift, fet/kursiv tekst, lister og lenker. Lenker åpnes i ny fane med beskyttende rel-attributter. Aktivt innhold som skript, hendelsesattributter, iframes og sporingsbilder fjernes.

Backend bruker vanlige tekstbokser med HTML-kildekode. De bevarer formateringen ved lagring, men er **ikke en visuell rikteksteditor**. Forhåndsvisning/sammenligning av import viser formatert tekst. Dansestil, navn og SEO/schema bruker ren tekst etter feltets formål. Denne utgaven innfører ingen ny teksteditor eller migrering.
