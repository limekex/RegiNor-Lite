# 0.1.28 – kompakt kursprofil og korrekte metadata

Testutgave 26. september 2026.

- På desktop ligger kursfakta, pris og påmelding på høyde med kursoverskriften. Beskrivelsen starter under tittelområdet i venstre kolonne. På mobil og i dokumentets leserekkefølge vises tittel → fakta/påmelding → beskrivelse.
- Reduserte avstander i toppen. Ingen fast høyde eller reservert tomt bildefelt.
- Lenken heter **Tilbake til kursperioden**, med samme periode og filterkontekst som før.
- RegiNor leverer én faktisk HTML-`title` på virtuelle kurs-, periode- og nivåvisninger når temaet bruker WordPress `title-tag`, også hvis en SEO-plugin har fjernet WordPress sin utskriftsfunksjon. Eldre temaer får tittelen gjennom `wp_title`.
- Avadas `insert_og_meta` deaktiveres for den aktuelle forespørselen når RegiNor leverer egne metadata. Dermed blandes ikke underliggende WordPress-sides beskrivelse, delingsbilde og URL inn i kursmetadata. Favicons, fonter og øvrige sider beholdes.
- Beskrivelse, canonical, Open Graph, Twitter-kort og schema beholdes. Delingsbilde følger eksisterende prioritet: kursets bilde → periodens bilde → RegiNors standardbilde. Velg et slikt bilde dersom bildeforhåndsvisning ønskes og ingen er satt.

## Funn før retting

Lesekontroll av den offentlige [Salsa øvet 1-siden](https://www.salsanor.no/kursrekke/host-3-2026/salsa-ovet-niva-1/) viste ingen HTML-`title`, to beskrivelser og to sett Open Graph. Det ekstra settet brukte beskrivelsen og URL-en til `/kurs/`. Det er bekreftet hva HTML-en manglet; hvilken installert komponent som fjernet WordPress sin tittelutskrift er ikke bevist gjennom denne lesekontrollen.

Avada-integrasjonen er kontrollert mot lokalt tilgjengelig kildekode for Avada 7.9.2 og 7.15.6 (`Avada_Head`, `insert_og_meta`, `wp_head` prioritet 5). WordPress sin [tittelutskrift](https://developer.wordpress.org/reference/functions/_wp_render_title_tag/) og Yoasts [metadata/presenters](https://developer.yoast.com/customization/apis/metadata-api/) forklarer hvorfor et tittelfilter alene ikke sikrer at en title-tag blir skrevet ut.

Meta-keywords er ikke lagt til: [Google bruker ikke dette feltet til indeksering eller rangering](https://developers.google.com/search/docs/crawling-indexing/special-tags). Kursnivå og dansestil brukes fortsatt i innholdet og relevant eksisterende merking.

## Verifikasjon

Lokalt bestått:

- `composer check`: syntaks og 231 tester / 575 assertions.
- WordPress-integrasjon, permalenker/metadata 63 og permalenke-HTTP 66. Tittel med og uten WordPress sin standardcallback, eldre tema, Avada-lignende callback, sikker escaping, beholdt favicon og uendrede vanlige sider er dekket. HTTP bekrefter én tittel med samme innhold som Open Graph.
- Offentlig visning 119 / HTTP 83, nivåarkiv-HTTP 21 og interface/DOM.
- Visuell Chrome-kontroll med lokalt Twenty Twenty-Five-tema på desktop og 390/320 px: påmelding ved siden av tittelen på desktop, riktig mobilrekkefølge, tydelig tilbakelenke og korrekt nettlesertittel. Egne testobjekter ryddet og lokale innstillinger gjenopprettet.
- POT regenerert. ZIP med 130 runtime-filer kontrollert byte for byte mot kilden.

Avada-hooken er kildekodekontrollert og prøvd med en stub; den fullstendige Avada-/SEO-kombinasjonen er ikke kjørt lokalt. Produksjonen er bare lest, ikke endret. Visuell kontroll og metadata må bekreftes etter installasjon i det faktiske Avada-/SEO-oppsettet.
