# 0.1.27 – nivåarkiver med relatert innhold

Testutgave 26. september 2026.

- Egne nivåarkiver under `/kursrekke/niva/<slug>/`, med publiseringsvalg, arkivtittel, HTML-introduksjon og ekstratekst.
- FAQ-er velges fra eksisterende innholdstype/taksonomi/stikkord og vises som korte utdrag med lenke til hele svaret.
- Artikler velges tilsvarende og vises i minimalistiske kort med bilde, tittel, utdrag og dato. Karusellen skifter hvert sjuende sekund og har piler, pause/start, tastatur, berøring og hensyn til redusert bevegelse.
- Separate arkivtekster og adresser per språk, med WPML-kobling til oversatte termer/innlegg. Felles kursdata og utvalgsinnstillinger dupliseres ikke per språk.
- Kursoversikten begrenses til nivået og tilgjengelige pågående/kommende perioder. Arkivtekstene består ved tomt kursutvalg. Nivåpiller lenker til publiserte arkiver.
- Egen canonical/OG, sitemap, aliaser, 404 etter avpublisering og no-store. `niva` reserveres for nye periodeadresser; eksisterende adressekonflikter gir vanlig spørreadresse og varsel fremfor automatisk omdøping.
- Gamle ACF-arkiver, taksonomier og relasjoner endres ikke. Ingen ny ACF-avhengighet.

Oppsett: **Kursinnhold og ressurser → Kursnivåer → nivået → Nivåarkiv på nettsiden**. Se [bruk og avgrensninger](../NIVAARKIVER.md).

## Verifikasjon

Lokalt bestått:

- `composer check`: PHP-syntaks og 231 tester / 575 assertions.
- WordPress-integrasjon, lagring (65), admin (117), arbeidsflyt (92) og admin HTTP (43).
- Permalenker (55) / HTTP (62), offentlig visning (119) / HTTP (83).
- Nye nivåarkivprøver (30) / HTTP (21): blant annet rettigheter, versjonskonflikt, HTML, egen FAQ-type/taksonomi, språkstubber, privat/passordbeskyttet innhold, alias, rutekollisjon, metadata og avpublisering. Bytte mellom kort og kalender beholder arkivadresse og nivåbegrensning.
- Interface/DOM inkludert avspilling, pause, fokus, piler, berøring og redusert bevegelse.
- POT generert, `git diff --check` uten feil og ZIP med 130 runtime-filer kontrollert byte for byte mot kilden.
- Lokal Chrome-kontroll av FAQ-liste og tekstkort på desktop og 390 px mobilbredde, inkludert pause/start og nivåavgrenset navigasjon. Syntetiske nettlesertestdata er ryddet.

Faktisk FAQ-type, bildevisning, WPML og Avada på produksjonsnettstedet må fortsatt prøves. WPML er prøvd med hook-stubber, ikke den faktiske pluginen. Lokal sidemal viste sin generelle sidetittel i tillegg til arkivets hovedoverskrift; skjul sidemalens tittel i Avada-oppsettet ved behov. Ingen produksjonsinnstillinger eller innhold er endret.
