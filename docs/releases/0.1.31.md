# 0.1.31 – instruktørvalg fra hovedspråket

Testutgave 27. september 2026.

Instruktørvelgeren hentet tidligere alle språkversjoner. Den viser nå bare publiserte, passordfrie profiler fra WPMLs hovedspråk, sortert på navn. Administrasjonens aktive språk endrer ikke utvalget. En oversettelse uten publisert hovedspråksprofil vises ikke som et alternativ.

Tidligere valgte oversettelser vises avkrysset på hovedprofilen. Ved neste lagring brukes hovedprofilen for de kurskveldene handlingen gjelder. Ingen automatisk migrering eller endring av gjennomførte kurskvelder. Uten WPML beholdes vanlig instruktørvalg.

Frontend fortsetter å hente navn og profillenke på besøkendes språk, med eksisterende tilbakefall når oversettelsen mangler.

## Verifikasjon

Lokalt: instruktørkontroller 33 med simulerte WPML-koblinger (tre språk, annet aktivt språk, manglende/kladdet hovedprofil og eksisterende utvalg), admin 117, oversettelsesoppstart, lagring 65, arbeidsflyt 92, redigering HTTP 43 og WordPress-integrasjon. Composer: 231 tester / 575 assertions. Testobjekter ryddes av testene.

Faktisk WPML-installasjon er ikke testet her. Frontend-renderingen er uendret; full offentlig HTTP-/interface-, API-, kalender- og analysesuite er ikke kjørt på nytt. Ingen produksjonsendringer.
